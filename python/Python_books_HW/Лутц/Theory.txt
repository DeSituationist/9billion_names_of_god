3.Если пользователь интерактивно вводит имя модуля для тестирования, то каким образом вы будете импортировать его в коде? С помощью exec('import ' + module)
4.Чем изменение sys.path отличается от установки PYTHONPATH для модификации пути поиска модулей? Первое изменяет путь поиска только на время процесса, второе постоянно
5.Если модуль __future__ позволяет импотировать из будущего, то можно ли импортировать из прошлого? Нет, так как от старых интсрументов отказываются и они перестают работать
